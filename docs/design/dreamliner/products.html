The kit — eight fields, no code

What Admin fills

1. productId and domain
2. Business question
3. Ingest: PUSH, FEED (their topic), or both
4. Event dependencies + universe policy
5. SLA
6. On-ready action and target
7. Report catalog, CEES, optional producer URL

What never forks

Event envelope, fold, snapshot, SSE, Control Tower card, Outcome cockpit, My Reports, Now task, maker-checker. If you need if (FOBO) in Java, the kit is wrong — add a field, not a branch.

The fold, in SQL

docs/schema/onefinux-stitch-queries.sql 
-- Sign-off / post enabled only when READY and the run echoed back
SELECT i.instance_id, i.status, cr.echo_ok,
       CASE WHEN i.status = 'READY' AND cr.echo_ok = 'Y'
            THEN 'ENABLE' ELSE 'DISABLE' END AS buttons
FROM outcome_instance i
LEFT JOIN command_run cr ON cr.run_id = i.run_id
WHERE i.kit_id = 'FOBO';

Fold rules

Count distinct keys, never event rows.

FAILED on a required key blocks the instance.

REVOKED withdraws an earlier completion.

A completion that does not echo run_id is ignored.

One fact can feed many outcomes; the kit decides who counts it.

LLM commentary is advisory and never on this path.

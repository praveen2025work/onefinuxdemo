One Finance UX — system map

Umbrella for group units and business outcomes. FOBO Helix is one kit, not the application.

Barclays navy #002D5F · cyan #00AEEF
Theme: /theme/onefinux-tokens.css

One entitled shell, one event fold, one theme. Other teams build heavy screens and we iframe them. Business analysts publish Wijmo grid, pivot, and chart when a source exists. Agents run the job; users sign off or post.

1 · Four jobs under the umbrella

Head · CEES groupUnit

Business-unit head

Track outcomes only: Ready / Blocked / Delayed / Escalated. Counts and SLA.

Does not post, open books, or edit kits.

User · product + outcome

Outcome user

Agents already ran (Helix FOBO, Axiom…). Open ready output. Sign off or post.

Does not configure sources or design pivots.

RTB · platform.support

Run the bank

Delays, aged, SLA miss, escalations. Dual-control replay. Dead letters.

Does not sign off a rec or publish a kit.

Config · platform.config

Onboard / BA

Group unit, bindings, kits, datasets. BA publishes FlexGrid / Pivot / Chart.

Does not perform COB sign-off. No React report per ask.

2 · Group unit (SAP / Tableau tenant)

Onboard a unit (Revenue Accounting, Product Control, Markets Ops…) = people + outcomes + datasets + Wijmo workspace. Shell does not fork. Dimensions: group unit · product · outcome instance · COB · region · slice · source · destination · renderer · entitlement.

3 · Runtime path (facts in, command out, humans last)

Their feedsCATS · MOTIF · MBR · SAP · Castle. We subscribe. No SoR poll. Teams that cannot notify us — we read their topic.
→
GatewayMap to onefinux.fact.v1. Idempotent id + offset. Watermark.
→
BusSolace or Kafka. Never in the browser. facts · commands · workflow · notify · advisory
→
Hub foldEvents are facts. Distinct keys. FAILED blocks. REVOKED withdraws. Completions echo runId. No if (FOBO).
→
DestinationsCommand Helix / Axiom / FAS. Notify P&L. We send alerts. Sources do not.
→
Human edgeCEES filter. REST snapshot + Spring SSE. Head · user · RTB · config.

Advisory LLM (Agent Analysis) sits beside the fold. Never a readiness input.
